Este repositorio tiene como propósito almacenar y organizar las evidencias de clase de la materia de Programación 1. Aquí se guardarán las prácticas, tareas y proyectos realizados durante el curso.

## Estructura del repositorio

**El repositorio está organizado de la siguiente manera:**

practicas: contiene las prácticas y ejercicios realizados durante las clases.
proyectos: contiene los proyectos desarrollados durante el curso.
README.md: contiene la información y documentación general del repositorio.
.gitignore: indica los archivos y carpetas que Git debe ignorar.

## Bitácora de instalación del IDE

**IDE utilizado:* Visual Studio Code (VS Code)**

**Versión:* 1.138.0**

Para trabajar durante el curso instalé Visual Studio Code como entorno de desarrollo para escribir y ejecutar código en Python.

 **Problemas durante la instalación:**

 Al instalar la extensión de python se corrompió un archivo que me impedía continuar con la clonacion 

 **Solución :**

 Desinstale y reinstale la extensión de python en visual code.

 1. Clona el repo

Abre la terminal, ve a la carpeta donde quieras guardarlo y escribe:

git clone https://github.com/ashleyruelas5083/ashley-ruelas-programacion-1
Eso crea una carpeta con el proyecto dentro.

2. Entra al proyecto

cd nombre-repo
3. Instala dependencias (si tiene)

Si hay package.json:

npm install
Si hay requirements.txt:

pip install -r requirements.txt
4. Ejecuta el proyecto

Depende del repo. Busca en el README.md las instrucciones. Suele ser algo como:

npm start
o

python main.py
5. Para trabajar y subir cambios

git checkout -b mi-rama        # crea tu rama
git add .                      # prepara cambios
git commit -m "mi cambio"      # guarda cambios
git push origin mi-rama        # sube tu rama
Luego entras a GitHub y creas un Pull Request.

6. Para traer cambios nuevos del repo original

git pull origin main
